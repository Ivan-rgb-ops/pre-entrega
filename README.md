# Pre-Entrega de Proyecto Node.js

Herramienta de consola (CLI) desarrollada en Node.js para gestionar productos de una tienda en línea interactuando de forma asíncrona con la **FakeStore API**.

---

## 🚀 Requisitos Previos
* Tener instalado **Node.js** (versión 18 o superior recomendada para utilizar `fetch` nativo).

---

## 💻 Comandos Disponibles
